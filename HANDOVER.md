# Handover

Обновлено: 23.10.2026, после вкладки «Письма». Этап: автоматизация работает, первый реальный запуск прошёл; ждём отзыва владельца.

## Проект

Система поиска клиентов для Tanbala (RFID-направление ТОО «VenMart», Алматы). Каждый день: казахстанские компании из 2ГИС, проверенная почта, причина «почему им подходит» и черновик письма. Письмо уходит только после одобрения человеком.

Пайплайн и статусы компании: `new` (2ГИС) → `crawled` (сайт) → `qualified` / `rejected` (Claude) → `verified` (Reacher) → `drafted` (черновик) → `approved` (человек) → `sent` → `replied`.

Правила работы: [CLAUDE.md](CLAUDE.md). Установка и запуск: [docs/SETUP.md](docs/SETUP.md).

## Открытые вопросы и известные ограничения

- Reacher с домашнего IP: SMTP-проверка даёт unknown (нет PTR и своего домена отправителя; tanbala.kz не существует в DNS, у venmart.kz SPF `-all`). Сейчас unknown считается годным, отсеиваем invalid. Полная проверка только на VPS со своим доменом.
- `web/app.py` 891 строка, больше потолка 800: можно разделить на запросы, форматирование и данные шаблонов.
- SSRF: остаётся теоретический DNS-rebinding (Python проверяет адрес, Chromium резолвит заново). Закрыть на VPS прокси или правилом брандмауэра для Chrome.
- Проверки кодом не ловят замаскированные ссылки (site[.]kz) и выдуманные факты: письмо всё равно читает человек.
- Сохраняются вопросы из прошлого этапа: подробное «ТЗ для Claude Code»; подтвердить документ о Tanbala; строгие правила базы; отдельный домен для рассылки.

## Решения и почему

| Решение | Почему |
| --- | --- |
| parser-2gis в отдельном окружении `.venv-2gis`, вызов как CLI | ему нужен pydantic<2, crawl4ai нужен pydantic>=2.10; в одном окружении не ставятся |
| Структура по 8 шагам пайплайна | раздела 5 подробного ТЗ нет, см. открытые вопросы |
| Список проверок писем в `checks.py` | раздела 3 ТЗ нет; взят из разделов 8, 11, 12 документа о Tanbala |
| Правила раздела 13 держит база | первое письмо на адрес и компании один раз (уникальные индексы в `contact_history`), триггер не даёт записать отправку адресу, домену с поддоменами или компании из `do_not_contact`, компанию с историей удалить нельзя |
| Порядок отправки (для `send.py`) | сначала строка в `contact_history`, потом SMTP, потом `drafts.sent_at`: сбой не даст повторного письма |
| Везде claude-haiku-5-5 | требование владельца; Sonnet только по его решению |
| `Anthropic(api_key=..., base_url=...)` явно | при явном ключе SDK 2.1 не ищет учётные данные в окружении; пустой ключ останавливает работу до создания клиента; base_url не даёт увести ключ через переменную окружения |
| В бесплатных тестах HTTP-запросы SDK заблокированы | защита бюджета; платные тесты только с `RUN_PAID=1` |
| Миграция 1 правилась до применения на сервере | база была пустой; дальше только новые миграции в конец `MIGRATIONS` |
| Сайт не открылся: работа продолжается по карточке 2ГИС | почта часто есть прямо в 2ГИС; иначе компания зависала бы на шаге «Сайты» |
| Незавершённые компании прошлых запусков дообрабатываются в пределах лимита запуска | ошибки API или Reacher временные; лимит запуска не растёт, а новые компании идут первыми |
| Компании без единой почты не уходят в Claude | писать некуда, вызов был бы потрачен зря |
| Суточный лимит `DAILY_API_BUDGET_USD` (по умолчанию $1, по времени Алматы) | бюджет владельца ограничен, кнопку можно нажать много раз |
| В письме допустим только наш номер WhatsApp | вредный текст на сайте мог бы подсунуть модели чужой номер |
| Ссылки `http://` из 2ГИС обходятся сначала по `https://` | переход http → https внутри браузера crawl4ai принимает за пустую страницу |
| Браузер crawl4ai в `.browsers`, всё остальное crawl4ai (global.yml, база, кэш) в `.crawl4ai` (пути задаёт `tanbala_leads/__init__.py`) | владелец требует держать всё в папке проекта: рядом агент сайта, файлы не должны смешиваться. Ставить и проверять только через `scripts/crawl4ai_tools.py` |

## Подводные камни

- Docker Desktop не стартует сам вместе с Windows.
- `.env` нельзя пересоздавать из `.env.example` начисто: пароль Postgres зашит в том `tanbala-leads_pgdata` при первом запуске. Если `POSTGRES_PASSWORD`, `DATABASE_URL` или `REACHER_SECRET` потеряны, их можно восстановить из `docker inspect` запущенных контейнеров (так и сделано 23.10.2026).
- Кириллица в выводе через Git Bash ломается: запускать с `PYTHONUTF8=1`.
- parser-2gis без всех трёх флагов `-i -o -f` не работает как CLI.
- В BEFORE-триггере Postgres генерируемая колонка ещё пустая: домен в `forbid_blocked_send` берётся из email.
- `scripts/crawl4ai_tools.py doctor` делает один тестовый запрос на crawl4ai.com.
- В crawl4ai 0.9.5 функция `migrations.run_migration()` жёстко смотрит в `~/.crawl4ai`. Пока этой папки нет, она ничего не делает. Не создавать `~/.crawl4ai` и не запускать штатные `crawl4ai-setup` / `crawl4ai-doctor`.
- В `C:\Users\bogda\AppData\Local\ms-playwright` лежат браузеры других инструментов (2025 год, глобальный Playwright 1.54). Это не наше, не трогать.
