## Проект

Система поиска клиентов для Tanbala (RFID-направление ТОО «VenMart», Алматы). Каждый день: казахстанские компании из 2ГИС, проверенная почта, причина «почему им подходит» и черновик письма. Письмо уходит только после одобрения человеком.

Пайплайн и статусы компании: `new` (2ГИС) → `crawled` (почты с сайта) → `qualified` / `rejected` (Claude) → `verified` (Reacher) → `drafted` (черновик) → `approved` (человек) → `sent` → `replied`. Каждый шаг пишет в базу и меняет статус, любой шаг перезапускается отдельно.

Правила работы: [CLAUDE.md](CLAUDE.md). Установка и запуск: [docs/SETUP.md](docs/SETUP.md).

## Решения и почему

| Решение | Почему |
| --- | --- |
| parser-2gis в отдельном окружении `.venv-2gis`, вызов как CLI | ему нужен pydantic<2, crawl4ai нужен pydantic>=2.10; в одном окружении не ставятся |
| Структура по 8 шагам пайплайна | раздела 5 подробного ТЗ нет, см. открытые вопросы |
| Список проверок писем в `checks.py` | раздела 3 ТЗ нет; взят из разделов 8, 11, 12 документа о Tanbala |
| Правила раздела 13 держит база | первое письмо на адрес и компании один раз (уникальные индексы в `contact_history`), триггер не даёт записать отправку адресу, домену с поддоменами или компании из `do_not_contact`, компанию с историей удалить нельзя |
| Порядок отправки (для `send.py`) | сначала строка в `contact_history`, потом SMTP, потом `drafts.sent_at`: сбой не даст повторного письма |
| Везде claude-haiku-5-5 | требование владельца; Sonnet только по его решению |
| `Anthropic(api_key=..., base_url=...)` явно | при явном ключе SDK 2.1 не ищет учётные данные в окружении; пустой ключ останавливает работу до создания клиента; base_url не даёт увести ключ через переменную окружения |
| В бесплатных тестах HTTP-запросы SDK заблокированы | защита бюджета; платные тесты только с `RUN_PAID=1` |
| Миграция 1 правилась до применения на сервере | база была пустой; дальше только новые миграции в конец `MIGRATIONS` |

## Подводные камни

- Docker Desktop не стартует сам вместе с Windows.
- Кириллица в выводе через Git Bash ломается: запускать с `PYTHONUTF8=1`.
- parser-2gis без всех трёх флагов `-i -o -f` не работает как CLI.
- В BEFORE-триггере Postgres генерируемая колонка ещё пустая: домен в `forbid_blocked_send` берётся из email.
- Вывод `crawl4ai-doctor` делает один тестовый запрос на crawl4ai.com.
