# Правила для Claude в этом проекте

- Пиши владельцу на русском, коротко.
- В начале работы прочитай [HANDOVER.md](HANDOVER.md). После каждого шага обновляй его и коммить вместе с изменениями: следующий чат продолжает по нему.
- Всё держим в этой папке. Не создавай файлов вне её, не сохраняй заметки в память Claude вне проекта, не пушь в удалённые репозитории без прямой просьбы.
- [knowledge/tanbala-agent.md](knowledge/tanbala-agent.md): документ владельца, не менять. ТЗ: [docs/TZ.md](docs/TZ.md). Если они противоречат друг другу, прав документ о Tanbala.
- Работаем по этапам. После этапа: отчёт (что работает, что нет и почему, что нужно от владельца, сколько токенов API потрачено) и ждать «ок». Модули проходим по одному вместе с владельцем.
- Один коммит на каждый пункт задания.

## Платный API

- Перед любым реальным вызовом Claude API спросить владельца: зачем, какая модель, сколько запросов и токенов.
- Сначала claude-haiku-5-5. На claude-sonnet-5-5 только по решению владельца, после примеров, где Haiku ошибся.
- Наборы 3–5 примеров. Разумный max_tokens. Документ о Tanbala кэшировать через prompt caching.
- Каждый реальный вызов в лог: модель, входные и выходные токены.
- Платные тесты не перезапускать после мелких правок, только после изменения промпта, модели или логики вызова.
- Что можно решить без AI (regex, правила, парсинг), решать без AI.
- Ключ только из VENMART_ANTHROPIC_KEY, передаётся явно. Стандартную переменную ключа Anthropic не использовать нигде: она переключит Claude Code владельца с подписки на оплату через API.
