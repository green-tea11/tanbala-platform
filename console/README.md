# Tanbala console — сервер единой панели

Сервер-посредник (BFF) единой панели `panel.tanbala.kz`: свой вход, сессии, роли, журнал действий; данные и действия
берёт только у почты (`leads/`, `127.0.0.1:8000/internal/console/*`) и бота (`whatsapp/`, `127.0.0.1:3101/internal/console/*`)
со своим токеном к каждому. Браузер токенов не видит. План — `docs/PLAN.md`, контракт с приложениями —
`../contract/CONSOLE_API.md`, API для интерфейса — `docs/API.md`.

Интерфейс (React/Vite, папка `web/`) — следующий этап. Пока `web/dist` нет, консоль отдаёт страницу-заглушку.

## Запуск

Node 22.12+ (на сервере 22.23). Пакеты ставятся без install-скриптов (`.npmrc`), better-sqlite3 приезжает готовым
бинарником внутри пакета.

```
npm ci
npm run build          # tsc → dist/
cp .env.example .env   # заполнить токены (см. ниже)
npm start              # node dist/server.js, слушает 127.0.0.1:3200
```

Пользователи заводятся только командой на сервере (в интерфейсе — только чтение):

```
node dist/cli.js user add <имя> [owner|manager]   # пароль спросит без эха (9–256 символов);
                                                  # без роли: первый — владелец, дальше — менеджеры
node dist/cli.js user passwd <имя>         # новый пароль, сессии пользователя закрываются
node dist/cli.js user role <имя> <owner|manager>
node dist/cli.js user disable <имя>        # отключить и закрыть сессии
node dist/cli.js user enable <имя>
node dist/cli.js user revoke <имя>         # закрыть все сессии
node dist/cli.js user list
node dist/cli.js --help
```

Пароль можно передать строкой через stdin (без терминала): `printf '%s\n' "$PASSWORD" | node dist/cli.js user passwd owner`.

## Проверка

```
npm run check          # typecheck + lint + тесты с покрытием (порог 80%)
npm test               # только тесты
```

Тесты только на моках: почта и бот подменены, сеть и порты закрыты (`tests/setup/no-network.ts`), сервер
проверяется через `inject`.

## Настройки (`.env`, только имена)

| Переменная | По умолчанию | Что |
| --- | --- | --- |
| `CONSOLE_HOST` | `127.0.0.1` | только 127.0.0.1 |
| `CONSOLE_PORT` | `3200` | порт консоли |
| `CONSOLE_ALLOWED_HOSTS` | пусто | домены за Caddy (`panel.tanbala.kz`), только HTTPS |
| `LEADS_API_URL` | `http://127.0.0.1:8000` | почта, только `http://127.0.0.1:<порт>` |
| `LEADS_CONSOLE_TOKEN` | — | токен к почте (секрет) |
| `WA_API_URL` | `http://127.0.0.1:3101` | бот, только `http://127.0.0.1:<порт>` |
| `WA_CONSOLE_TOKEN` | — | токен к боту (секрет), не равен токену почты |
| `CONSOLE_DATABASE_PATH` | `data/console.db` | база консоли, только внутри `data/` |
| `LOG_LEVEL` | `info` | уровень журнала |

Консоль не стартует, если токен не задан или неверного вида, токены совпадают, адрес приложения не
`http://127.0.0.1:<порт>`, база вне `data/` или включён прокси Node для fetch (`NODE_USE_ENV_PROXY`,
`--use-env-proxy`). Ошибка называет переменную, но не значение.

## Устройство

- `src/config` — разбор `.env`. `src/db` — SQLite: пользователи (scrypt), сессии (только SHA-256 id), журнал
  (180 дней), отметки «видел». `src/auth` — пароли, ограничитель входа, сессии, вход.
- `src/backends` — клиенты почты и бота: адрес из шаблона, таймаут, предел ответа, `redirect: 'error'`, проверка
  схемой, свежая копия JSON, объединение одинаковых чтений и кэш 1.5 с, не больше 4 запросов сразу.
- `src/domain` — расход по таблице цен, заметка «Вернуть боту», «писали после письма», полоса режима, тексты.
- `src/services` — главная, карточки клиента и компании, расход по дням, уборка базы.
- `src/server` — fastify: хуки (Host, HTTPS, Origin, JSON, сессия, роль, CSRF, заголовки), маршруты `/api/*`,
  статика `web/dist`, `/healthz`. `src/cli` — команда `user`.
